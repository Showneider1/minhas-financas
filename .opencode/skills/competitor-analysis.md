# Skill: competitor-analysis

## Objective
Analyze existing fintech products to identify industry standards, gaps, and opportunities for differentiation.

## Context
Used during product discovery to avoid reinventing the wheel and to find ways to provide a superior experience.

## Prerequisites
- List of direct and indirect competitors (e.g., Mint, YNAB, local banking apps).

## Execution Procedure
1. **Feature Mapping**: Create a matrix of competitors vs. core features.
2. **UX Audit**: Analyze the onboarding, data entry, and reporting flows of competitors.
3. **SWOT Analysis**: Identify Strengths, Weaknesses, Opportunities, and Threats for Finance OS relative to each competitor.
4. **Gap Analysis**: Identify "must-have" features (table stakes) and "delighter" features (differentiation).
5. **Synthesis**: Recommend specific features or improvements for the backlog.

## Technical Patterns
- Feature Comparison Matrix.
- UX Teardowns.
- Value Proposition Canvas.

## Examples
- Comparing "Investment Portfolio" views across 3 top apps to find the best way to display XIRR.

## Validation Criteria
- Competitor matrix is complete.
- Clear differentiation strategy documented.
- Actionable insights translated into backlog items.

## Common Errors
- Copying features without understanding why they exist.
- Focusing only on the "best" app and ignoring common user complaints.

## Security Rules
- Respect competitor Terms of Service during analysis.

## Deliverables
- Competitor Analysis Report.
- Feature Gap Matrix.
- Differentiation Strategy.
