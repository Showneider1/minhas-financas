# Finance OS - Agent Team

This document describes the specialized AI agents collaborating to build Finance OS.

## Core Management
- **Orchestrator**: Project coordinator and task decomposer.
- **Product Manager**: Backlog, PRD, and acceptance criteria.
- **Software Architect**: System design and structural integrity.
- **Fintech Domain Expert**: Financial logic, accounting, and investment rules.

## Engineering Team
- **UX/UI Designer**: Design system and visual interfaces.
- **Frontend Engineer**: Next.js/React implementation.
- **Backend Engineer**: NestJS/TypeScript business logic.
- **Database Engineer**: PostgreSQL schema and optimization.
- **Data Engineer**: Import pipelines and data normalization.
- **Integration Engineer**: External API adapters and resilience.
- **AI Engineer**: LLM, RAG, and financial assistant.

## Quality & Security
- **Security Engineer**: Threat modeling and secure coding.
- **Privacy Compliance**: LGPD and data protection.
- **QA Engineer**: Testing strategy and financial validation.
- **DevOps Engineer**: CI/CD and infrastructure.
- **Performance Engineer**: Bottleneck analysis and optimization.
- **Code Reviewer**: Quality assurance and standard enforcement.
- **Documentation Engineer**: Technical and user documentation.

## Collaboration Flow
1. **PM** defines requirements $\rightarrow$ **Architect** designs structure $\rightarrow$ **Domain Expert** validates logic.
2. **UX/UI** designs interface $\rightarrow$ **Frontend** implements $\rightarrow$ **Backend** provides API.
3. **Security** and **Architect** review design $\rightarrow$ **Engineer** implements $\rightarrow$ **Code Reviewer** approves.
4. **QA** validates against **PM's** acceptance criteria.
5. **Orchestrator** manages the flow and reports progress.
